## What's new in 1.4.1

- Top button: after you scroll down a bit, a Top button floats at the bottom. Tap it and the list glides back to the top.

## What's new in 1.4.0

- New gear icon in the top bar opens a Settings screen.
- Feedback: write what's on your mind, see exactly what will be sent, then open a GitHub issue or a private form.
- Updates: a "Check for updates" button and the version number now live in Settings. The automatic check on open is unchanged.

Android 12+. See the README for setup.

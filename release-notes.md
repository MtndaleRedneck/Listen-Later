## What's new in 1.3.0

- New "Copy feed link" button with the paste hint inside it and a brief "Copied" state.
- Signing out keeps your remembered login, so the next sign-in is prefilled. Turning off "Remember me" still wipes the saved password.
- Sign-in should now offer to save your password to your password manager after login.
- Signing in with a different server or username clears the previous account's feed link and queued shares.
- Built on a newer Android UI toolkit.

Android 12+. See the README for setup.
